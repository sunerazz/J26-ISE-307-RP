# J26-ISE-307-RP
# AI-Based Intelligent EV Charging Prediction and Decision Support Framework

## Project ID
J26-ISE-307-RP

## Project Overview

This project develops an AI-based intelligent EV charging management and decision support system. The system integrates four main research components to provide predictive and intelligent charging support for electric vehicle users.

## Research Components

### Component 1 – Queue Length, Waiting Time and Congestion Prediction
Predicts:
- Queue Length
- Expected Waiting Time
- Congestion Level

### Component 2 – Charging Duration and Expected Completion Time
Predicts:
- Charging Duration
- Expected Completion Time

### Component 3 – Battery Consumption and Charging Cost
Predicts:
- Battery Consumption
- Estimated Charging Cost

### Component 4 – Charging Station Recommendation and Route Optimization
Provides:
- Charging Station Recommendation
- Station Ranking
- Route Optimization
- Context-aware station selection
